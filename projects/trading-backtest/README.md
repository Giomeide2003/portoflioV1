# Trading Strategy Backtest

Projet personnel d’apprentissage consacré au backtesting d’une stratégie quantitative simple sur des séries de prix.

## Objectif

Comprendre les principales étapes d’un backtest :

- construction d’un signal de trading ;
- génération des positions ;
- calcul des rendements de la stratégie ;
- mesure de la performance et du risque ;
- analyse des limites du backtest.

Le projet sera développé progressivement afin de comprendre chaque étape plutôt que d’utiliser une librairie de backtesting toute faite.

## Stratégie initiale

Le premier signal étudié sera un **croisement de moyennes mobiles** : une position longue est prise lorsque la moyenne mobile courte passe au-dessus de la moyenne mobile longue.

Aucune performance de marché n’est revendiquée à ce stade : le projet sert avant tout à comprendre la mécanique d’un backtest.
