# Option Pricing — Black-Scholes

Projet personnel d’apprentissage consacré au pricing d’options européennes avec le modèle de Black-Scholes.

## Objectif

Comprendre et implémenter progressivement les principales briques d’un pricer :

- prix d’un Call et d’un Put ;
- paramètres du modèle ;
- tests numériques ;
- Greeks ;
- volatilité implicite.

Le projet est développé progressivement afin de documenter les hypothèses, les choix de modélisation et les limites du modèle.
